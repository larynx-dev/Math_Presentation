§ I · Set theory

Set notation

Problem 1. Roster to set-builder

Write the set A in set-builder notation.

A = {2, 4, 6, 8, 10}
Solution.

All elements are the even numbers from 2 to 10:

A = {x | x = 2n, n ∈ ℕ, 1 ≤ n ≤ 5}

Problem 2. Set-builder to roster

Write the set B in roster form.

B = {x ∈ ℤ | −3 < x ≤ 4}
Solution.

The integers greater than −3 and at most 4:

B = {−2, −1, 0, 1, 2, 3, 4}

§ II · Linear algebra

Matrix operations

Problem 3. Matrix operations

Using A and B, find (a) 2A − B and (b) AB.

A = 2134,  B = 1−205
Solution.

(a) 2A − B = 3463(b) AB = 21314

Each entry of AB is a row of A times a column of B, e.g. 3·(−2) + 4·5 = 14

Problem 4. Determinant (2×2)

Find the determinant of M.

M = 4726
Solution.

For a 2×2 matrix: det = ad − bc

det M = 4·6 − 7·2 = 24 − 14

det M = 10

§ III · Differential calculus

Slope and the derivative

Problem 5. Slope of a curve

Find the slope of the curve at x = 6.

y = 2x2,  x = 6
Solution.

The slope is the derivative: y′ = 4x

At x = 6: y′(6) = 4 · 6

slope = 24

Problem 6. Derivative

Find the derivative of the function.

5x5(12x2 + 4)
Solution.

Expand first: 60x7 + 20x5

Apply the power rule to each term:

420x6 + 100x4
